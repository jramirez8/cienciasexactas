# Ciencias Exactas

Implementación web de la plataforma educativa diseñada en Figma Make.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```

La aplicación incluye la landing pública, acceso simulado, portal del alumno y panel administrativo. Los botones de demo permiten recorrer todos los perfiles sin credenciales reales.
